# Security Policy

## Supported Versions
Currently, only `v1alpha` (main branch) receives security updates.

## Reporting a Vulnerability
If you discover a vulnerability that allows an autonomous agent to bypass the Context Firewall (Zero-Edge Rejection or Strict Constraint Elevation), please DO NOT open a public issue.

Send an email detailing the boundary traversal flaw to the maintainers. We will issue a patch within 48 hours.
