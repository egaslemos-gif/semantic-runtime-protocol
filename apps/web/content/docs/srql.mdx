## O que é SRQL

SRQL (Semantic Runtime Query Language) é a linguagem de consulta do SRP runtime. Permite consultar o grafo arquitectural, testar traversals, e auditar decisões do firewall.

## Sintaxe básica

```
TRAVERSE FROM server.auth
  WITH DEPTH 2
  ALLOW depends_on, owns
  DENY frontend.*
```

## Resultado

```json
{
  "status": "COMPLETED",
  "nodes_visited": 3,
  "violations": 0,
  "path": ["server.auth", "server.auth.middleware", "server.persistence"]
}
```

SRQL é determinística — a mesma query sobre o mesmo grafo produz sempre o mesmo resultado.
