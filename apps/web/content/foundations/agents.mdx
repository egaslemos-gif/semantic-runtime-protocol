## O que é um AI Agent

Um AI agent é um sistema que usa um modelo de linguagem para **tomar decisões e executar acções** em loop. Diferente de uma chamada simples a uma API, um agente:

- Planeia (decompõe a tarefa)
- Executa (usa ferramentas)
- Observa (avalia resultados)
- Itera (ajusta a estratégia)

## Onde os agentes falham

Agentes não falham por falta de inteligência. Falham por **ausência de fronteiras operacionais**.

Sob pressão de complexidade:

- **Prompt drift**: o comportamento diverge da intenção ao longo de iterações
- **Scope leakage**: o agente acede a contexto fora do scope autorizado
- **Architectural drift**: alterações incrementais corrompem a arquitectura

Estes não são bugs do modelo. São **falhas da infraestrutura que envolve o modelo**.

## O que os agent frameworks resolvem

Frameworks como LangGraph, CrewAI, e AutoGen resolvem **orquestração**: como coordenar agentes, definir fluxos, gerir estado.

## O que os agent frameworks não resolvem

Nenhum framework de agentes resolve **governança de scope**: o que o agente pode ver e alcançar dentro de cada step.

Esta lacuna é exactamente onde o SRP opera.
