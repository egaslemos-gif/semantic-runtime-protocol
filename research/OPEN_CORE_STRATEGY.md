# Open Core Strategy

The Semantic Operating System must balance rapid global adoption of its core protocol with sustainable enterprise monetization for its advanced governance capabilities. We achieve this through a strict Open Core model.

## The Open Source Kernel (SRP Free)
The fundamental ability to compile and traverse semantic context must be free and open-source to establish SRP as the industry standard protocol.

- **`@repo/core` Engine:** The BFS Traversal Engine, Context Query Engine, and Graph Immutability Singleton.
- **Manifest Generator:** The compiler that turns Markdown/Frontmatter into `manifest.json`.
- **Public Adapters:** Claude MCP, Cursor Rules, and Basic JSON adapters.
- **SRP Spec (`v1alpha`):** Full access to the protocol definitions.
- **Basic Capability Matrix:** Standard depth and budget limiting.

## The Enterprise Tier (SRP Advanced)
Enterprise environments require deep auditability, multi-tenant isolation, and adversarial protection. These features form the commercial offering.

- **Advanced Governance Entropy Metrics:** Mathematical measurement of graph decay, circular dependency detection, and semantic drift warnings.
- **Adversarial Query Firewall (`query-sanitizer`):** The advanced canonicalizer that deflects sophisticated Prompt Injection and Fuzzy Hallucination attempts.
- **Query Replay Architecture:** Deterministic snapshot diffing to ensure cross-agent consistency over time (Behavioral Drift protection).
- **Enterprise CI Integration:** Deep assertion blocking for GitHub Actions/GitLab CI with full compliance reporting.
- **Runtime Introspection Console:** The live `PLAYGROUND_SCOPE_GOVERNANCE` visualizer for team leads to monitor agent traversal heatmaps.

*Note: The monorepo currently contains all code. The structural migration of Enterprise features into `@repo/enterprise` will occur during Phase 6 (Monetization & Packaging).*
